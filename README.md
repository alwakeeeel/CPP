## How to run a program

1. Make sure you have a C++ compiler installed, such as `g++`.
2. Open a terminal in the folder containing the source file.
3. Compile the file (replace `main.cpp` with the filename):

   ```bash
   g++ main.cpp -o main
   ```

4. Run the program:

   - **Windows PowerShell:** `./main.exe`
   - **Linux/macOS:** `./main`
